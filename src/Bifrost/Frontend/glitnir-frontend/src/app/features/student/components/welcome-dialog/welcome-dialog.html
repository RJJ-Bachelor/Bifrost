Din oplevelse med Bifrost bliver væsentligt forbedret, hvis du slår notifikationer til, så du får besked med det samme, når der er nyt i dine spørgsmål.

Du kan også tilgå Bifrost på telefonen og overføre din anonyme brugerdata til mobilen, så notifikationer også modtages der.

Begge dele finder du under Indstillinger () i øverste højre hjørne.
